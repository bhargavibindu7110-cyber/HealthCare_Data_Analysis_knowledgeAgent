# Healthcare Data Analysis Knowledge Agent

## Project Description
A beginner-friendly Healthcare Data Analysis Knowledge Agent
that uses Retrieval-Augmented Generation (RAG) to retrieve
relevant information from healthcare documents and answer questions.

## Technologies Used
- Python
- Google Colab
- RAG (Retrieval-Augmented Generation)
- Healthcare Data Analysis
- LLM

## Features
- Retrieve information from healthcare documents.
- Answer questions based on available information.
- Help users explore healthcare-related data.

## How to Run
Open the Jupyter Notebook in Google Colab and execute
the cells in order.

## Disclaimer
This project is for educational purposes only and does not
replace professional medical advice.
